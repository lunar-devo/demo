# Lunar Timewalker — demo

The 30-second demo video and the 7-slide presentation of **Lunar Timewalker**, Team Letmein's project for the NASA Space Apps Challenge 2026 (challenge: Lunar Landing Site Navigator; Devran Atuğ, Sakarya, Türkiye).

- Demo page: https://lunar-devo.github.io/demo/
- Video (English narration and captions): https://lunar-devo.github.io/demo/lunar-timewalker-demo.mp4
- Slides (PDF): https://lunar-devo.github.io/demo/lunar-timewalker-slides.pdf
- Turkish versions, for the local event in Sakarya: [video](https://lunar-devo.github.io/demo/lunar-timewalker-demo-tr.mp4) (Turkish narration and captions) · [slides](https://lunar-devo.github.io/demo/lunar-timewalker-slides-tr.pdf)
- The app: https://lunar-devo.github.io/ · Source code: https://github.com/lunar-devo/lunar-timewalker

Both are screen captures of the app. The data sources and software licences are listed on the last slide and in the source repository's README. The video's narration is an AI text-to-speech voice (Microsoft Edge neural TTS, via the edge-tts package) and its words are the captions; the background score is synthesized by our own script. No image was made by an AI image generator; the app's code was written with SI (AI) coding assistants.
